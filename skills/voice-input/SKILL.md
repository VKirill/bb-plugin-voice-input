# Голосовой ввод BB

Плагин регистрирует голосовой сервис `local-voice`, и BB отдаёт ему записи из
чата. Распознавание идёт на машине, где работает сервер BB; аудио наружу не
уходит.

## Включение

Голосовой сервис выбирается настройкой BB, а не плагином:

```
bb settings ai-services              # список доступных сервисов
bb settings set BB_TRANSCRIPTION local-voice/default
```

Дальше движок разворачивается на машине:

```
bb voice-input setup                 # ставит выбранный в настройках движок
bb voice-input setup gigaam          # конкретный движок
bb voice-input status                # что установлено и готово
```

Облачным движкам установка не нужна — только ключ в настройках (вкладка
«Облако»). `setup` ставит пакеты и может занять минуты; модель дозагружается при первом
распознавании. Для Whisper и GigaAM нужны Python 3 и ffmpeg на машине.

## Движки

| Движок | Чем считает | Когда выбирать |
| --- | --- | --- |
| `whisper` | mlx-whisper на Apple Silicon | Русский и смешанная речь, названия инструментов; выбор по умолчанию |
| `gigaam` | GigaAM v3 e2e (Сбер), torch на MPS | Сплошной русский: быстрее и с пунктуацией, но коверкает латиницу |
| `groq` | whisper-large-v3-turbo в облаке | Ставить нечего, есть бесплатный уровень; аудио уходит наружу |
| `openai` | gpt-4o-transcribe в облаке | Ставить нечего, точность высокая; аудио уходит наружу |
| `google` | gemini-3.5-transcribe в облаке | То же для Google; ключ из Google AI Studio |

## Настройки

Правятся в Settings → Installed plugins или через `bb plugin config voice-input`.

- **Движок**, **модель Whisper** (turbo быстрее, large-v3 точнее), **язык**
  (`auto` для смешанной речи, явный — для коротких фраз).
- **Словарь терминов** — простой список через запятую: `DeepSeek, Claude Code,
  env, BB`. Искажения перечислять не нужно: их находит починка по согласному
  костяку слова. Для упрямых случаев можно задать замену явно:
  `Claude Code = клодкод`.
- **Очистка текста** — слова-паразиты и кавычки-ёлочки, каждое правило отдельно.
- **ИИ-проход** — необязательная правка текста моделью по OpenAI-совместимому
  адресу: падежи, пунктуация, сильно искажённые термины. Сбой прохода не теряет
  расшифровку.
- **Сохранение записей** и срок хранения. Пока запись на диске, сбой
  распознавания не уничтожает сказанное.

## Проверка и разбор проблем

```
bb voice-input status                # движки, Python, ffmpeg, число записей
bb voice-input history 5             # последние расшифровки и пути к аудио
bb voice-input transcribe <путь>     # распознать файл на машине: проверка и разбор старых записей
bb voice-input config                # показать настройки
bb voice-input config engine gigaam  # изменить настройку
bb voice-input download              # скачать модель заранее, с прогрессом
bb voice-input apply-settings        # доставить настройки на машины
```

Записи и лог демона лежат в каталоге данных плагина на машине распознавания —
его печатает `status`. Если BB жалуется на недоступную транскрипцию, сначала
`status`, затем лог `voiced.log` рядом с записями.

Штатный таймаут голосовой транскрипции в BB — 10 секунд на попытку; длинная
запись в него не укладывается независимо от движка.
